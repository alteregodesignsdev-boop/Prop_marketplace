**OVERVIEW**

A free **Marketplace-themed** custom prop and mapping pack, designed and optimized for RedM environments. This package features modular source assets separated for maximum flexibility, along with a ready-to-use harbor integration.

> 📦 **Roadmap:** This repository will receive regular updates, including new free props, texture variations, and mapping expansions at no extra cost.

---

**PACKAGE STRUCTURE**

The resource comes fully organized into individual files:

* **3D Models & Definitions:**
  * `.ydr` files (3D Meshes & Geometry)
  * `.ytd` files (Optimized Texture Dictionaries)
  * `.ytyp` file (Archetype definitions & bounds)
* **`dock_marketplaceBK/`:** Ready-to-stream subfolder containing a lightweight `.ymap` that places and details the props across the docks.
